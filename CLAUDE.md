# Personal Portfolio

## Project Vision

This project is my personal portfolio.

Its primary purpose is not to demonstrate advanced frontend design skills.

Instead, it must communicate that I am a backend-oriented software developer capable of designing, building and maintaining complete software solutions.

Every design and technical decision must reinforce professionalism, clarity and technical quality.

The portfolio should feel modern, clean and lightweight rather than visually extravagant.

---

# Target Audience

The website is intended for:

- Software companies
- Technical recruiters
- Potential freelance clients
- Other software developers

The content must be understandable for both technical and non-technical visitors.

---

# Main Objectives

The portfolio exists to:

- Showcase personal software projects.
- Demonstrate software engineering skills.
- Build a professional online presence.
- Generate freelance opportunities.
- Make it easy for recruiters to contact me.
- Allow visitors to download my CV.

---

# Technology Stack

The portfolio must be developed using:

- React
- TypeScript
- Vite
- React Router
- Framer Motion
- CSS Modules or Tailwind CSS (prefer the simplest solution)

Do NOT use:

- Bootstrap
- Vuetify
- jQuery

---

# Languages

The website must support:

- English
- Spanish

A language switcher must be available at all times.

Translations should not be hardcoded throughout the project.

Use a proper internationalization strategy.

---

# Design Philosophy

The design should be inspired by:

- Brittany Chiang Portfolio

Important principles:

- Minimalistic
- Professional
- Elegant
- Clean
- Lots of whitespace
- Dark theme by default
- Excellent readability

Avoid:

- Glassmorphism everywhere
- Excessive gradients
- Flashy animations
- Bright colors
- Decorative icons without purpose

Content is more important than decoration.

---

# Responsive Design

The project must follow a Mobile First approach.

It should look excellent on:

- Mobile
- Tablet
- Desktop

---

# Accessibility

Accessibility is mandatory.

Follow WCAG recommendations whenever possible.

Requirements:

- Keyboard navigation
- Visible focus states
- Semantic HTML
- Correct heading hierarchy
- ARIA attributes only when necessary
- Proper color contrast

---

# Performance Goals

Target Lighthouse scores:

Performance >= 95

Accessibility >= 95

Best Practices >= 95

SEO >= 95

Optimize:

- Images
- Fonts
- Bundle size
- Lazy loading
- Motion performance

Avoid unnecessary JavaScript.

Every page should contain meaningful metadata.

# Coding Standards

Always use:

- TypeScript strict mode
- Functional Components
- React Hooks
- Reusable components
- Small files
- Clear folder structure

Avoid:

- any
- duplicated code
- deeply nested components
- unnecessary abstractions

---

# Component Rules

Components should have a single responsibility.

If a component exceeds approximately:

- 250 lines
- multiple responsibilities
- excessive props

Claude should recommend splitting it.

---

# Design System

Maintain consistency using:

- Shared spacing scale
- Typography scale
- Shared color palette
- Consistent border radius
- Consistent shadows
- Reusable UI components

Do not invent new styles for every page.

---

# Animations

Use Framer Motion.

Animations must be:

- Smooth
- Fast
- Subtle

Animations should enhance UX, never distract from it.

---

# Architecture Principles

The codebase should serve as a demonstration of software engineering quality.

Prioritize:

- Readability
- Maintainability
- Scalability
- Simplicity

Prefer explicit code over clever code.

---

# Decision Rules

Claude should:

- Prefer simple solutions.
- Reuse existing components.
- Avoid adding dependencies without justification.
- Explain architectural decisions.
- Ask before making major UI changes.
- Preserve visual consistency.

Never sacrifice readability for cleverness.

---

# What This Portfolio Should Communicate

Visitors should leave with the impression that:

- I build robust software.
- I specialize in backend development.
- I understand full stack development.
- I value clean architecture.
- I pay attention to software quality.
- I write maintainable code.
- I am someone they would trust to build real-world applications.

# Brand Personality

The portfolio should communicate:

- Professionalism
- Humility
- Technical competence
- Curiosity
- Continuous learning
- Attention to detail

It should never feel arrogant or self-promotional.

The focus is to demonstrate real engineering skills through projects and code quality rather than making exaggerated claims.

Every page should answer one implicit question from the visitor:

"Would I trust this developer to work on my software?"
